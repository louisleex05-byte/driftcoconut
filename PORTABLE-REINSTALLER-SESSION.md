## How reinstall works

1. Copy ZIP to new laptop (USB / OneDrive / email)
2. Unzip anywhere
3. PowerShell:
   ```powershell
   cd C:\path\to\driftcoconut-workflow-portable
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\install.ps1
   ```

## What the automated installer does (7 steps)

1. **Checks prerequisites** — Git for Windows + Node.js LTS (fails clearly if missing)
2. **Asks destination** — default `C:\Users\<you>\Downloads\Travel Site`
3. **Clones repo** — from `https://github.com/louisleex05-byte/travel-site.git`
4. **Runs `npm install`** — fetches Next.js + all dependencies (~2 min)
5. **Copies workflow app** — into repo root (.ps1, .bat, README, config)
6. **Copies 7 skeletons** — into `guides-drafts/` (gitignored, local-only)
7. **Sets up `.env.local`** — from `.env.example` (user fills in Agoda keys later)

Prints next-step commands on completion (git config, launch app, npm run dev).

## What the ZIP does NOT carry (intentional)

- `node_modules/` — regenerated by `npm install`
- `.next/` build cache — regenerated by `npm run dev`
- `content/guides/*.mdx` — already in GitHub repo, cloned fresh
- `public/guides/*` (photos) — already in GitHub repo, cloned fresh
- `.git/` — cloned fresh
- `.vercel/` — cloned fresh (auto-links to Vercel project via project ID)

**Design principle:** GitHub is the source of truth. The ZIP only carries the local-only workflow tooling (workflow app + skeletons + reference docs) that isn't tracked in git.

## Troubleshooting shortcuts

| Problem | Fix |
|---|---|
| "Execution of scripts is disabled" | `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned` |
| Missing `git` / `npm` | Install prerequisites, restart PowerShell, re-run |
| WinForms window doesn't open (PS7+) | `powershell.exe -File .\guide-workflow.ps1` (force PS 5.1) |
| Git push rejected | `git config --global user.email "louisleex05@gmail.com"` + GitHub PAT |
| Vercel not auto-deploying | Verify project link at https://vercel.com/dashboard |
